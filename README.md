# Disaster Rescue Detection using YOLOv8

## Overview

This project uses YOLOv8 and OpenCV to detect people in disaster-affected areas from images. The system identifies individuals, draws bounding boxes around detected persons, and generates a processed output image.

## Features

* Person detection using YOLOv8
* Bounding box visualization
* Detection count
* Processed image output

## Technologies Used

* Python
* YOLOv8 (Ultralytics)
* OpenCV

## How to Run

1. Activate the virtual environment
2. Install dependencies from requirements.txt
3. Run:

python detect.py

## Output

The processed image is saved in the outputs folder as result.jpg.
